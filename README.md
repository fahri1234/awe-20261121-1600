A deterministic Node.js program that writes one original, quiet deep-time scene to `entry.txt`. The single-file implementation uses only the standard library and makes no network requests.

## Run it

```sh
node main.ts
```

By default, the program writes `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose another output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/awe-output node main.ts
```

The output is UTF-8 text with no trailing newline. See [NOTES.md](NOTES.md) for the design choices and verification results.
